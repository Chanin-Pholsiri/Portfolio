# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Recruiters and HR screeners, in Thailand and abroad. They skim quickly for role titles, companies, dates, stack and location.
- Tech leads and hiring managers. They look for technical depth: the systems Chanin has owned, the scale they run at, and code on GitHub.
- Prospective freelance clients who want a website or system built. Secondary audience; the site's main goal is a full-time role.

## Product Purpose

Personal portfolio for Chanin Pholsiri, a full-stack software engineer based in Bangkok with 5+ years of experience. It exists to get Chanin a full-time role in Thailand, remote, or through relocation abroad. Success is a visitor reaching out by email or downloading the resume.

## Positioning

Chanin works across the whole stack and across domains: business websites, enterprise web applications and regulated fintech. The fintech work is one strand, not the whole profile. The strongest single proof point is being the only engineer who owns every Spring Boot API of a national financial enforcement system connected to every bank and non-bank financial institution in Thailand, handling 300–600 cases per day.

## Operating Context

- Single-page site with sections: Hero, About, Skills, Experience, Projects, Education, Certifications, Contact.
- Visitors arrive from job applications, LinkedIn and GitHub, on desktop and mobile.
- Calls to action: email (chaninpholsiri@gmail.com) and resume download (`public/Chanin_Pholsiri_Resume.pdf`).

## Capabilities and Constraints

- Built with Next.js App Router, React 19, TypeScript, Tailwind CSS v4 and Framer Motion. Statically prerendered.
- English only. No Thai version is planned.
- Light and dark themes follow the OS setting (`prefers-color-scheme`); both must stay supported.
- The Financial Crime Prevention API System is confidential. Do not add screenshots, client names or any detail beyond what the site already states.
- G-Able enterprise work is also private: no links or source.

## Product Principles

1. A recruiter skimming for 30 seconds should find role, years, stack, location and how to make contact.
2. Show the range of work (web, enterprise, fintech), not only fintech.
3. Confidential work is described, never shown.
4. Real proof over claims: named companies, dates, scale numbers and linked code.

## Accessibility & Inclusion

- Muted text must meet WCAG AA contrast in both themes.
- Keyboard accessible, with visible focus states.
- Respect `prefers-reduced-motion`.
